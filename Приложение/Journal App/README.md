# Приложение для ведения журналов

Это многопользовательское приложение для учета, распределения и контроля статусов журналов в общей сетевой базе данных.

Приложение позволяет нескольким пользователям одновременно работать с журналами, отслеживать их статусы и видеть изменения в реальном времени.

---

## ✨ Возможности

- просмотр списка журналов;
- поиск и фильтрация по журналам и статусам;
- взятие журнала в работу;
- завершение обработки журнала;
- автоматическое обновление статусов у всех пользователей;
- редактирование данных журналов для администраторов;
- удаление записей;
- импорт журналов из сетевой папки;
- работа с выгрузкой данных из Excel;
- отображение статистики выгрузки;
- рейтинг по журналам и по месяцам;
- ведение месячных планов и контроль выполнения.

---

## 👥 Роли пользователей

### Обычный пользователь
- просматривает журналы;
- берет журнал в работу;
- завершает обработку;
- видит актуальные статусы в реальном времени.

### Администратор
- имеет все возможности обычного пользователя;
- редактирует записи;
- удаляет журналы;
- импортирует данные;
- управляет рейтингом и месячными планами;
- работает с Excel-выгрузками.

---

## ⚙️ Особенности

- многопользовательская работа;
- хранение данных в общей SQLite-базе на файловом сервере;
- автоматическое обновление изменений без ручной перезагрузки;
- разделение прав доступа;
- удобный интерфейс с вкладками для разных сценариев работы.

---

## 🗂️ Основные вкладки

### 📚 Журналы
Список всех журналов с возможностью поиска, фильтрации и изменения статусов.

### 📤 Скачать из Elibrary и выгрузить в WindChill
Раздел для работы с данными из Excel и контроля статусов выгрузки.

### 🏆 Рейтинг
Статистика по выполнению, рейтинги пользователей и планирование по месяцам.

---

## 💾 Хранение данных

- **База данных:** SQLite
- **Расположение:** общий файловый сервер
- **Обновление данных:** автоматическое, для всех подключенных пользователей

---

## 🚀 Назначение

Приложение предназначено для ускорения и упрощения работы с журналами в коллективной среде, где несколько сотрудников одновременно работают с одной общей базой данных.

---

## 📌 Примечание

Приложение рассчитано на одновременную работу нескольких пользователей и автоматически синхронизирует изменения между ними.
